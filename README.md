# 📚 Repositório de Aulas - Engenharia e Desenvolvimento

Este repositório centraliza o conteúdo programático, materiais de apoio e códigos práticos das disciplinas ministradas. Abaixo está a ementa resumida de cada módulo.

---

## 🌐 1. Arquitetura IoT (Internet das Coisas)
Focado no desenvolvimento de soluções conectadas, abordando desde o hardware na borda até a integração com a nuvem.
*   **Hardware & Ecossistema:** Exploração da plataforma **Arduino** e microcontroladores (ESP32/Atmega).
*   **Firmware (C++):** Programação de baixo nível para controle de sensores, atuadores e gerenciamento de memória.
*   **Integração (Python):** Scripts para gateways, processamento de dados e comunicação via protocolo MQTT.

## 📋 2. Levantamento de Requisitos
Aborda as etapas de engenharia de software para elicitação, análise e documentação de necessidades de negócio.
*   **Elicitação:** Técnicas práticas de **Brainstorming** e condução de **Entrevistas** com stakeholders.
*   **Classificação:** Definição e separação de Requisitos Funcionais (RF) e Não Funcionais (RNF).
*   **Modelagem:** Criação de **Diagramas UML** (Casos de Uso, Atividades) e prototipagem de telas.
*   **Especificação:** Construção de Relatórios Técnicos, Histórias de Usuário e documentos de especificação.

## 💻 3. Lógica de Programação
Base fundamental de desenvolvimento de algoritmos, boas práticas de versionamento e preparação de ambientes.
*   **Algoritmos (Python):** Sintaxe básica, estruturas condicionais, laços de repetição, listas e funções.
*   **Controle de Versão:** Uso essencial de **Git** (commits, ramificações) e hospedagem de portfólio no **GitHub**.
*   **Ambientes de Desenvolvimento:** Configuração, terminais e execução de código multiplataforma:
    *   **Windows:** PowerShell, CMD e variáveis de ambiente (PATH).
    *   **Linux:** Terminal Bash, gerenciadores de pacotes (`apt`/`dnf`) e permissões.
    *   **iOS:** Alternativas móveis através de IDEs na Nuvem (Replit/Codespaces) e apps dedicados.

## 💻 3. Lógica de Programação e Sistemas Operacionais
Base fundamental de desenvolvimento de algoritmos, preparação de ambientes de desenvolvimento e boas práticas de versionamento de código.
*   **Algoritmos (Python):** Sintaxe básica, estruturas condicionais, laços de repetição, coleções e funções.
*   **Controle de Versão:** Uso essencial de **Git** (commits, fluxo local) e gerenciamento de portfólio no **GitHub**.
*   **Sistemas Operacionais & Ambientes:** Configuração, uso de terminais (CLI) e execução de código multiplataforma:
    *   **Windows:** Prompt de Comando (CMD), PowerShell, gerenciador `winget` e variáveis de ambiente (PATH).
    *   **Linux:** Terminal Bash, gerenciadores de pacotes nativos (`apt`/`dnf`) e atribuição de permissões de arquivos.
    *   **iOS:** Desenvolvimento móvel através de IDEs na nuvem (Replit/Colab) e ecossistemas sandbox.
